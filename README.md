# 揮桿即時檢測 Swing Check

用手機鏡頭即時檢測高爾夫揮桿動作的網頁工具。手機架好之後，它會自動偵測每一次揮桿，揮完約 1 秒用語音說出這一球最該調整的一件事，下一球就能馬上修正。

A browser-based golf swing checker. Prop up your phone, swing, and it tells you by voice the one thing to fix before the next ball. Everything runs on the device; no video ever leaves the phone. (UI is in Traditional Chinese.)

## 兩種用法

- **現場即時提醒**：手機架好，每一球揮完用語音告訴你最該改的一件事，下一球馬上修正
- **事後檢視**：每一球可以產生一張「關鍵畫面」，把站位、引桿、頂點、擊球、收桿五格排在一起並加上參考線，自己對照檢查球桿的位置。也可以載入用相機 App 拍好的影片來分析（建議 60fps，不要用慢動作模式）

## 特色

- 免手持：自動偵測站位、上桿、擊球、收桿，不用每球按按鈕
- 揮桿前逐項確認：全身入鏡 → 雙手握桿 → 站位鎖定，沒過關會用畫面和語音說明原因，過關會說「站位OK」
- 語音播報：揮完播報最重要的一項；動作太慢或沒被當成揮桿時，也會說明原因
- 兩種拍攝角度：背後（沿目標線）與正面，可自動判斷
- 每球數值紀錄，可複製成文字
- 關鍵畫面可以存成一張圖片，方便留紀錄或傳給別人看
- 練習紀錄：每次練習結束自動記下球數、頭部下沉、站位前傾等中位數，可以看跨次練習的趨勢
- 每一球自動錄成短片，可以分享出去請人看；也能匯出偵測資料（關節點座標）方便除錯
- 也可以選一段已拍好的影片來分析
- 不需要安裝 App、不需要帳號、不需要伺服器

## 檢測項目

| 拍攝角度 | 項目 |
|---|---|
| 背後（沿目標線） | 下桿頭部下沉、站位上半身前傾角、提早起身、上桿節奏、頂點停頓、站位膝蓋角度 |
| 正面 | 下桿頭部下沉、擊球時重心移轉、頭部左右晃動、引桿時手肘與肩膀（三角形）、收桿重心、上桿節奏、頂點停頓 |

背後角度還會在揮桿前檢查站位，站得太直會先提醒。

## 使用方式

相機只能在 `https://` 網址下開啟。這個專案用 GitHub Pages 部署：

1. Fork 這個專案
2. 到 Settings → Pages，把 Source 改成 **GitHub Actions**
3. 到 Actions 頁面，執行「Deploy to GitHub Pages」（之後每次推送到 `main` 都會自動部署）
4. 約一分鐘後，用手機瀏覽器開啟 `https://<帳號>.github.io/<專案名稱>/`
5. 按「開始檢測」，允許使用相機

部署流程（`.github/workflows/pages.yml`）會從 npm 下載固定版本的 MediaPipe Pose，和 `index.html` 一起放上網站，所以專案裡不需要存放模型檔。

### 架設手機

1. 手機直立，固定在大約腰部的高度，全身從頭到腳都要入鏡
2. 背後角度：鏡頭在身後，沿著目標線看出去。正面角度：鏡頭正對胸口
3. 握桿站好不動約 1 秒，聽到「站位OK」或站位的修正提醒後就可以揮桿
4. 手機要關閉靜音模式，球場吵的話建議戴耳機

畫面右上角會顯示每秒處理的格數（fps）。低於 12 時快速的下桿可能抓不到，請把「偵測模型」改成「輕量」。

## 隱私

- **影像完全在你的裝置上處理**，不會上傳到任何地方。程式裡沒有任何上傳、統計或追蹤的程式碼
- 使用時偵測模型和程式都由同一個網站提供，不會連到第三方伺服器
- 只在瀏覽器的 localStorage 存你的設定（拍攝角度、身高等選項）和練習紀錄（每次練習的幾個統計數字），不含影像
- 每球紀錄、錄下的短片和偵測資料都只存在這個網頁的記憶體裡，關掉網頁就消失。只有你自己按「複製紀錄」「分享影片」「匯出偵測資料」時才會離開網頁
- 匯出的偵測資料包含關節點座標、設定和瀏覽器的裝置資訊（User-Agent），不含影像
- 不想錄影可以在設定裡關掉「錄下每一球」；「錄影畫質」可選 1080p 或 720p，高畫質時只保留最近 8 球
- 和任何網站一樣，網站空間的提供者（例如 GitHub Pages）看得到來訪的 IP 位址

## 限制

- 姿勢偵測只抓身體關節，**抓不到球桿和手指**，所以桿面、揮桿平面、桿頭路徑、握法都無法檢測。「雙手握桿」只代表雙手靠在一起、放在身體前方
- 慢動作的練習揮桿不會被分析；正常速度的空揮會
- 公分數是由畫面估算的，適合比較每一球之間的變化，不是精確量測
- 判斷門檻是依一般教學原則和少量實際影片訂的，不能取代教練的判斷
- 鏡頭沒有擺正時（例如斜後方），角度類的數值會偏小
- 引桿時的桿身方向和桿面角度沒有自動判斷，要用「關鍵畫面」自己看

## 調整門檻

所有門檻都在 `index.html` 裡 `LIMITS` 這個物件，例如：

| 名稱 | 預設 | 意義 |
|---|---|---|
| `headDrop` | 0.04 | 頭部下沉超過身體尺度的 4%（約 5 公分）就提醒 |
| `tiltAddrMin` | 25 | 站位上半身前傾小於 25° 視為站太直 |
| `backswingFast` | 0.55 | 上桿時間短於 0.55 秒視為太急 |
| `pause` | 0.25 | 頂點停頓超過 0.25 秒就提醒 |
| `shiftImp` | 0.03 | 擊球時髖部往目標移動不到 3% 視為重心沒過去 |

「身體尺度」是站位時耳朵到腳踝的垂直距離，程式用身高的 75% 換算成公分。

## 技術

- 程式只有一個 `index.html`，沒有相依套件管理
- 姿勢偵測使用 [MediaPipe Pose](https://github.com/google-ai-edge/mediapipe)（BlazePose），部署時放在網站的 `vendor/pose/`
- 語音使用瀏覽器內建的 Web Speech API

### 在自己的電腦上執行

```bash
npm pack @mediapipe/pose@0.5.1675469404
tar xzf mediapipe-pose-0.5.1675469404.tgz
mkdir -p vendor && mv package vendor/pose
npx serve .        # 或任何靜態網頁伺服器
```

在 `localhost` 可以開相機；用手機連區域網路的 IP 則不行，因為不是 https。
